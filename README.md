# robertwissing.github.io

Personal academic homepage, served by GitHub Pages as plain HTML/CSS (no build step).

- `index.html` – the whole site on one scrolling page (About, Research, Publications, CV sections)
- `assets/css/style.css` – all styling
- `assets/img/` – photo and figures
- `assets/movies/` – simulation movies (mp4); see the comment in the Movies section for embed snippets
- `assets/cv/Wissing_CV.pdf` – the CV (the menu links straight to it)
- `assets/slides/` – talk and lecture slides (PDF); see the comment in the Slides section

Draft placeholders are highlighted in yellow (`class="todo"`); search for `todo` to find them.
To preview locally: `python3 -m http.server` and open http://localhost:8000.

## Publications

The first-author and co-authored lists in `index.html` are generated by
`scripts/publications/update_publications.py`. It queries NASA ADS by ORCID
(0000-0001-7039-4592), pulls titles, authors, venues and abstracts, and merges
them with `scripts/publications/entries.json`. That file keeps the papers ADS
may not have, the "My contribution" notes, venue overrides such as
"Submitted to A&A", and extra links such as Code. Edit `entries.json`, never the
generated block between the `PUBLICATIONS:START`/`END` markers. The Theses list is
written by hand.

The GitHub Actions workflow `.github/workflows/update-publications.yml` runs the
script every Monday and on demand (Actions → Update publications from ADS → Run
workflow), and commits only when something changed. It needs an ADS API token
in the repository secret `ADS_API_TOKEN`.

Run it locally with `ADS_API_TOKEN=... python3 scripts/publications/update_publications.py`,
or with `--offline` to rebuild from `entries.json` alone.
